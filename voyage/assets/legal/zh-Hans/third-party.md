# Voyage 第三方信息共享清单

版本：7
更新日期：2026 年 10 月 22 日
生效日期：2026 年 10 月 20 日

## 说明

本清单列出 Voyage 工具箱集成的第三方 SDK，以及各工具在您使用时直接连接的主要第三方服务。本清单是[《隐私政策》](voyage-legal://privacy)的组成部分。

第三方 SDK 和服务由其提供方独立处理您的信息，并适用其各自的隐私政策。我们会在 SDK 更新或新增时及时更新本清单。

## 一、第三方 SDK

### Apex 广告 SDK

- 提供方：ApexAdx
- 使用场景：激励视频广告与冷启动时的开屏广告。**仅在您同意广告服务后初始化**，未同意时不会加载。
- 处理的信息：设备标识（OAID、Android ID）、设备品牌、型号、系统版本、屏幕参数、网络类型、运营商、IP 地址、应用包名与版本、广告展示与点击记录，以及您已为其他功能授予的位置、电话状态等权限范围内的信息。
- 处理目的：广告投放、广告效果统计、反作弊。已启用个性化广告推荐。
- 我们提供的信息：激励视频与开屏广告的广告位、经签名的账号编号（用于发放观看奖励与区分账号）和展示场景。

Apex 广告 SDK 基于 ToBid 聚合 SDK 构建，并按其策略调度以下渠道的 SDK 展示广告。这些 SDK 同样**仅在您同意广告服务后初始化**，处理的信息和目的与上一项相同，具体以各自的隐私政策为准：

- ToBid 聚合 SDK 与 Sigmob 广告 SDK，提供方：北京创智汇聚科技有限公司
- 穿山甲（GroMore）广告 SDK，提供方：北京巨量引擎网络技术有限公司
- 优量汇广告 SDK，提供方：深圳市腾讯计算机系统有限公司，隐私政策：https://e.qq.com/dev/help_detail.html?cid=2005&pid=5983
- 快手广告 SDK，提供方：北京快手广告有限公司，隐私政策：https://u.kuaishou.com/home/detail/1290
- 百度百青藤广告 SDK，提供方：北京百度网讯科技有限公司
- 倍孜广告 SDK（AdScope），提供方：北京倍孜网络技术有限公司
- ZJ 广告 SDK（ZJSDK）
- 简信广告 SDK
- JY 广告 SDK

各渠道的隐私政策链接以 Apex 提供的个人信息保护规则为准。

### 移动安全联盟 OAID 组件（Android_CN_OAID）

- 使用场景：在您同意广告服务后读取设备的开放匿名设备标识符（OAID），供广告 SDK 使用，并作为本应用设备标识的来源之一。
- 处理的信息：OAID。
- 处理方式：在本机调用设备厂商提供的接口读取，组件本身不联网。

### 友盟+ 统计 SDK

- 提供方：友盟同欣（北京）科技有限公司
- 使用场景：统计本应用的使用情况，包括启动次数、使用时长、访问的页面、打开的工具，以及版本和渠道分布，用于改进产品。**仅在您同意本政策后初始化**；您可以在「设置 → 隐私 → 使用情况统计」中关闭，关闭后不再初始化。
- 处理的信息：设备标识（OAID、Android ID、友盟生成的设备标识）、设备品牌、制造商、型号、系统版本与构建信息、处理器架构、屏幕分辨率、网络类型、运营商、IP 地址、应用版本与渠道、使用时长和页面访问记录；您登录后还包括您的账号编号（不含账号名、手机号和电子邮件地址）。**我们已关闭 IMEI、IMSI、ICCID、Wi-Fi MAC 地址和已安装应用列表的采集。**
- 处理目的：统计分析。
- 隐私政策：https://www.umeng.com/page/policy

### 友盟+ 应用性能监控 SDK

- 提供方：友盟同欣（北京）科技有限公司
- 使用场景：发现和修复本应用的故障与性能问题，包括崩溃、无响应、卡顿、启动耗时、内存占用、耗电和网络请求性能。**仅在您同意本政策后初始化**，与友盟+ 统计 SDK 共用「设置 → 隐私 → 使用情况统计」开关，关闭后下次启动起不再初始化。
- 处理的信息：设备标识（OAID、Android ID、友盟生成的设备标识）、设备品牌、型号、系统版本、处理器架构、屏幕分辨率、剩余存储空间、网络类型、运营商、IP 地址、应用版本与渠道；崩溃或卡顿时的线程堆栈、系统日志片段、内存与电量状态、当时所在的页面和最近的操作记录；抽样的网络请求的地址、耗时与状态码；本应用写下的警告和错误日志（保存在本机，仅在排查故障时由我们发起回捞才上传）。
- 处理目的：稳定性与性能分析。
- 隐私政策：https://www.umeng.com/page/policy

### Google Analytics for Firebase

- 提供方：Google LLC
- 使用场景：统计本应用在海外及有 Google Play 服务设备上的使用情况，包括启动次数、使用时长、访问的页面、打开的工具，以及版本和地区分布，用于改进产品。**仅在您同意本政策后初始化**，与友盟+ 统计 SDK 共用「设置 → 隐私 → 使用情况统计」开关，关闭后立即停止采集。**我们已关闭广告标识符的采集和广告个性化信号。**
- 处理的信息：Firebase 安装标识与应用实例标识、设备型号、系统版本、语言、由 IP 地址推断的国家或地区、应用版本、会话与页面访问记录、打开的工具；您登录后还包括您的账号编号（不含账号名、手机号和电子邮件地址）。
- 处理目的：统计分析。信息由 Google 在中华人民共和国境外的服务器处理。
- 隐私政策：https://firebase.google.com/support/privacy

### Firebase Crashlytics

- 提供方：Google LLC
- 使用场景：发现和修复本应用的崩溃，包括原生代码崩溃。**仅在您同意本政策后初始化**，与友盟+ 统计 SDK 共用「设置 → 隐私 → 使用情况统计」开关；关闭后停止上传，并删除尚未上传的崩溃报告。您同意本政策后，还会把同意之前 30 天内、最多 20 条本机崩溃记录补报一次。
- 处理的信息：Firebase 安装标识、设备型号、系统版本、处理器架构、屏幕方向、剩余内存与存储空间、是否已获取 root 权限、应用版本；崩溃时的线程堆栈、当时所在的页面、最近打开的工具与本应用写下的警告和错误日志；您登录后还包括您的账号编号。
- 处理目的：稳定性分析。信息由 Google 在中华人民共和国境外的服务器处理。
- 隐私政策：https://firebase.google.com/support/privacy

### Firebase Performance Monitoring

- 提供方：Google LLC

- 处理目的：性能分析。信息由 Google 在中华人民共和国境外的服务器处理。
- 隐私政策：https://firebase.google.com/support/privacy

### Firebase Cloud Messaging

- 提供方：Google LLC

### 本机运行的开源组件

## 三、各工具直接连接的第三方服务

以下服务在您主动使用对应工具时才会被访问。本应用把请求直接发送给这些服务，**不经过我们的服务器**。这些服务会接收到您的 IP 地址和请求内容。

### 涉及位置的服务

- Open-Meteo（open-meteo.com）：摄影辅助的天气与云量、指南针的海拔，接收您的坐标。
- Sunrise-Sunset（sunrisesunset.io）：摄影辅助的日出日落时间，接收您的坐标。
- 挪威气象局（api.met.no）：摄影辅助的天气预报，接收您的坐标。
- BigDataCloud（bigdatacloud.net）：摄影辅助、油价查询、速度表行程起止点的地名解析，接收您的坐标。
- OpenStreetMap Overpass：速度表的道路限速、油价的附近加油站，接收您的坐标。
- OpenFreeMap（tiles.openfreemap.org）：速度表行程轨迹与加油站地图的底图，接收地图显示区域。

### 涉及图片的服务

- trace.moe、AnimeTrace：以图搜番，接收您选择或截取的图片。
- img.scdn.io：图床，接收您选择上传的图片。
- uapis.cn：智能抠图接收您选择的图片；部分查询类工具接收您输入的查询内容。

### 涉及设备信息的服务

- maclookup.app：网络地址工具查询厂商，接收您查询的 MAC 地址。

### AI 与语音服务（由您自行配置）

- AI 对话、朋友圈文案改写、录音待办的云端大模型：OpenAI、Anthropic、Google Gemini、DeepSeek、阿里云百炼、火山方舟、智谱、月之暗面、硅基流动、OpenRouter、xAI、Groq、Mistral，或您填写的兼容接口和 MCP 服务器。接收您的对话内容、附件和工具调用结果。
- 录音待办的云端语音识别（阿里云百炼）和云端语音合成（OpenAI 兼容接口、硅基流动）：仅在您选择云端服务后，接收音频或文本。
- 系统语音识别服务：AI 对话的语音输入，由您设备上的系统语音识别服务提供方处理。

### 第三方平台账号

- 网盘（阿里云盘、夸克、UC、115、123 云盘、天翼云盘、移动云盘、微云、迅雷云盘等）：接收您的登录凭据和上传的文件。
- 视频解析账号、喜马拉雅、无畏契约（WeGame）、中国象棋等：接收您在对应平台的登录凭据或 Cookie。
- AI 水印解析（豆包、千问、元宝、通义）：接收您在内置网页登录后取得的 Cookie，用于读取您自己的素材。

### 内容与查询服务

视频解析、音乐解析、在线影视、在线短剧、在线小说、在线漫画、在线听书、在线听歌、IPTV 直播、搜题、磁力搜索、快递查询、油价、汇率、天气、食品条码（Open Food Facts）、鸟类资料（iNaturalist）等工具会把您输入的链接、关键词或查询条件发送给对应的网站或接口。具体来源以各工具内显示的来源名称为准。
