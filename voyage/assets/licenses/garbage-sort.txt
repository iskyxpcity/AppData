Waste sorting dictionary (assets/garbage/dictionary.tsv.gz)

The bundled dictionary is compiled from the open data sets below and revised
for common items against GB/T 19095-2019. Item names and categories were
merged, deduplicated and re-encoded; no source code from these projects is
included.
